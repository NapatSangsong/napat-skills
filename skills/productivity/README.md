# Productivity Skills

Skills for engineering communication, documentation, and process.

| Skill | Trigger | Description |
|-------|---------|-------------|
| `post-mortem` | `/post-mortem`, "write the RCA", "document this fix" | Write the canonical engineering record of a fixed bug |
| `management-talk` | `/management-talk`, "executive summary", "make this less technical" | Rewrite engineering content for leadership audiences |
| `fable-5` | `/fable-5`, "break this down", hard/ambiguous multi-step task | Disciplined loop for hard tasks — decompose by verification boundaries, verify against the world, choose next by plan-change (ships `fable-scout` + `fable-refuter` agents) |
