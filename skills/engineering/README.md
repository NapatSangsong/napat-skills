# Engineering Skills

Skills for debugging, auditing, fixing, and reviewing .NET / SharePoint / frontend development issues.

| Skill | Trigger | Description |
|-------|---------|-------------|
| [`nuget-audit`](nuget-audit/SKILL.md) | `/nuget-audit`, TypeLoadException, MissingMethodException | Scan and fix NuGet package version conflicts across all .NET project types |
| [`debug-mantra`](debug-mantra/SKILL.md) | `/debug-mantra`, bug reports, stack traces | Four-step debugging discipline: reproduce, trace, falsify, cross-reference |
| [`scrutinize`](scrutinize/SKILL.md) | `/scrutinize`, "review this", "sanity check" | Outsider-perspective end-to-end review of plans, PRs, or code changes |
| [`blackduck-nuget`](blackduck-nuget/SKILL.md) | `/blackduck-nuget`, Black Duck scan results | Analyze Black Duck scans, compare baselines, upgrade .NET Framework packages |
| [`coverity-frontend`](coverity-frontend/SKILL.md) | `/coverity-frontend`, Coverity DOM_XSS/URL_MANIPULATION | Fix Coverity frontend JS/HTML security issues with proven patterns |
| [`coverity-backend`](coverity-backend/SKILL.md) | `/coverity-backend`, Coverity RESOURCE_LEAK/FORWARD_NULL/CSRF | Fix Coverity backend C#/.NET security & quality issues with proven patterns |
